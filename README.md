# Kaido

Website for **Kaido**, the iPhone app that logs every drive and maps every road you've driven, car by car.

- Privacy policy: https://taikiish.github.io/kaido/privacy.html
- Support: https://taikiish.github.io/kaido/support.html

Served with GitHub Pages from the `main` branch. Plain HTML and one stylesheet, no build step.
